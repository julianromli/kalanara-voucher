# Refactor Clean Plan

## Phase 1: Exploration
- [ ] Analyze `package.json` for existing tools (`knip`, `depcheck`, `ts-prune`) and test scripts.
- [ ] Understand project structure and key directories (API, components, lib, etc.).
- [ ] Determine how to run tests (unit, integration, e2e).

## Phase 2: Analysis & Reporting
- [ ] Run `knip` (unused exports/files).
- [ ] Run `depcheck` (unused dependencies).
- [ ] Run `ts-prune` (unused TS exports).
- [ ] Compile findings into `.reports/dead-code-analysis.md`.
- [ ] Categorize findings (SAFE, CAUTION, DANGER).

## Phase 3: Cleaning Strategy
- [ ] Define "SAFE" deletion candidates (test files, unused internal utils).
- [ ] Establish test verification loop command (e.g., `bun run test`).

## Phase 4: Execution (Iterative)
- [ ] For each safe candidate:
    - [ ] Run tests (baseline).
    - [ ] Delete code.
    - [ ] Run tests (verification).
    - [ ] Revert if failure.

## Phase 5: Final Review
- [ ] Update report with actions taken.
- [ ] Verify build integrity.
